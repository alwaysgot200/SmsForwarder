# 保活过时/无用措施统一清理方案

## 一、背景与目标

前序评估结论（已经用户确认）：Cactus 大部分机制在 Android 11+/ColorOS 上已失效或有害；开机广播里 `startActivity` 拉界面在 Android 10+ 被系统拦截；`PACKAGE_RESTARTED` 注册空挂；"在最近任务列表中隐藏"对保活反效果。用户指令：**把过时的、不适用的、无用的措施统一处理好**。

清理原则：只删失效/无用/重复项，**不损害有效保活链路**（前台服务+通知、忽略电池优化、精确闹钟看门狗、KeepAliveWorker、解锁自愈、开机/覆盖更新自愈）。

### 3. 空挂/重复广播清理

3.1 [AndroidManifest.xml](file:///e:\_android_work\SmsForwarder\app\src\main\AndroidManifest.xml#L316) L316：删除 BootCompletedReceiver 的 `<action android:name="android.intent.action.PACKAGE_RESTARTED" />`。理由：onReceive 无对应分支；该广播在进程被强停时发出，而强停状态下的进程收不到任何广播，注册永不生效。

3.2 [AndroidManifest.xml](file:///e:\_android_work\SmsForwarder\app\src\main\AndroidManifest.xml#L330-L338) L330-338：**整个 LockScreenReceiver 的 manifest 注册块删除**，三个 action 无一生效：
- `SCREEN_OFF` / `SCREEN_ON`：Android 不会把这两个广播投递给 manifest 静态注册的接收器（只能动态注册）——死注册；
- `android.intent.action.ACTION_USER_PRESENT`：动作名写错（真实动作是 `android.intent.action.USER_PRESENT`），从未匹配——死注册。

实际锁屏/解锁任务触发由 [App.kt](file:///e:\_android_work\SmsForwarder\app\src\main\kotlin\cn\ppps\forwarder\App.kt#L251-L258) 动态注册完成，删除零行为变化。

3.3 [LockScreenReceiver.kt](file:///e:\_android_work\SmsForwarder\app\src\main\kotlin\cn\ppps\forwarder\receiver\LockScreenReceiver.kt#L28-L32)：删除 onReceive 开头的解锁自愈块（`USER_PRESENT` 时拉起前台服务），保留其后的锁屏任务触发逻辑。去重依据：同一自愈已由 [BootCompletedReceiver.kt](file:///e:\_android_work\SmsForwarder\app\src\main\kotlin\cn\ppps\forwarder\receiver\BootCompletedReceiver.kt#L45-L51) 的 USER_PRESENT 分支承担，且它是 manifest 注册（进程死亡时系统会拉起进程投递），覆盖面严格更大、条件完全相同；进程存活时两者同时触发，第二个因 `ForegroundService.isRunning` 判空跑，纯冗余。

## 四、关于"开机自动启动"（回答用户提问）

Android 上的"开机自启"分两个层次，现状如下：

1. **自启服务/进程（可行，官方标准做法，已实现并保留）**：manifest 注册 `BOOT_COMPLETED` + `LOCKED_BOOT_COMPLETED` 接收器 → `startForegroundService`。开机广播是 Android 12+ 前台服务后台启动限制的豁免场景，能稳定拉起前台服务，这就是转发类应用的正统开机自启。生效前提（缺一则静默失效）：
   - App 至少被手动打开过一次（全新安装/清数据后处于"停止状态"收不到广播）；
   - ROM 允许自启动（ColorOS 需在 设置→应用→自启动 中放行，App 设置页已有跳转指引）；
   - 用户没有"强行停止"过 App（强停后所有广播、闹钟失效，直到手动再打开）。
2. **自启界面（Android 10+ 官方不可能）**：后台启动 Activity 被系统全局禁止，开机广播也不例外。唯一例外是 ROM 专属授权（ColorOS 的"后台弹出界面"权限），不通用、不推荐依赖——本次按你的决定删除该代码路径。界面不需要开机弹出：前台服务 + 通知常驻即完成保活，转发不受影响。

配套自愈网已齐：精确闹钟看门狗、KeepAliveWorker、解锁自愈（USER_PRESENT）、覆盖更新自愈（MY_PACKAGE_REPLACED），删掉界面自启后无保活缺口。
